# ⛅ Weather Tracker (React Native & Expo)

Мобільний застосунок для моніторингу погоди, побудований на **React Native (Expo SDK 57)** та безкоштовному API **[Open-Meteo](https://open-meteo.com)** (без потреби в API-ключах чи реєстрації).

Застосунок дозволяє шукати міста, переглядати детальний поточний прогноз та погоду на 7 днів, зберігати обрані локації та переглядати закешовані дані в режимі офлайн.

---

## 🚀 Швидкий старт

### 1. Передумови
- Встановлений [Node.js](https://nodejs.org/) (версія 18+)
- Мобільний додаток **Expo Go** на телефоні (iOS / Android) або налаштований симулятор.

### 2. Встановлення залежностей
```bash
npm install
```

### 3. Запуск проекту
```bash
npm run start
# або з очищенням кешу бандлера:
npx expo start -c
```
Відскануйте згенерований QR-код у терміналі за допомогою камери (на iOS) або через додаток Expo Go (на Android).

### 4. Перевірка якості коду та тести
```bash
# Перевірка типів TypeScript
npm run typecheck

# Перевірка лінтером ESLint
npm run lint

# Запуск тестів Jest
npm run test

# Запуск тестів з генерацією Coverage звіту
npm run test:cov
```

## 🛠 Технологічний стек

- **Фреймворк:** React Native 0.86, Expo SDK 57 (Expo Router v57 file-based routing)
- **Мова:** TypeScript (строгий режим `strict: true`, без `any`)
- **Серверний стан та кешування:** TanStack Query v5 (`@tanstack/react-query`)
  - `staleTime: 5 хвилин` (запобігає надлишковим повторним мережевим запитам)
  - `gcTime: 24 години` (зберігає дані для повноцінного офлайн-доступу)
- **Локальний стейт-менеджмент:** Zustand v5 + `@react-native-async-storage/async-storage` з `safeAsyncStorage` fallback
- **Геолокація:** `expo-location` (з обробкою дозволів та зворотним геокодингом)
- **Іконки:** `@expo/vector-icons` (Ionicons) — без використання системних емодзі
- **Тестування:** Jest + `ts-jest` (96.6% coverage бізнес-логіки та утиліт)

## ✨ Реалізований функціонал (Must have)

### 1. Пошук міста
- Інпут з `useDebounce` (~400 мс) для зменшення кількості запитів до Geocoding API.
- Випадаючий список результатів із назвою міста, регіоном та країною.

### 2. Екран міста та детальний прогноз
- Поточна температура, "відчувається як", вологість та швидкість вітру.
- Опис та векторні іконки згідно з міжнародними кодами WMO (`weather_code`).
- Прогноз на 7 днів (максимальна/мінімальна температура, ймовірність опадів у %).
- Pull-to-refresh для примусового оновлення даних.
- Кастомна навігаційна кнопка повернення назад.

### 3. Улюблені міста
- Додавання та видалення міста з обраного одним тапом на сердечко.
- Захист від створення дублікатів міст.
- Персистентне збереження списку між перезапусками додатку.
- Картки обраних міст на головному екрані з актуальною температурою та погодною іконкою.

### 4. Робота в офлайні та кешування
- При втраті інтернет-з'єднання додаток показує останні збережені дані з кешу TanStack Query.
- Відображається статусний банер **"Offline Mode • Updated X mins ago"**.

### 5. Геолокація ("Моя локація")
- Кнопка швидкого визначення поточного місцезнаходження через GPS (`expo-location`).
- Коректна обробка відмови у наданні дозволу (permission denied).

### 6. Налаштування та UI/UX
- **Перемикач одиниць виміру:** перемикання між °C та °F на льоту, збереження вибору в сховищі.
- **Темна та світла теми:** повна адаптація палітри інтерфейсу під темну/світлу тему або системний режим.
- **Єдиний капсульний контролер (`HeaderControls`):** компактний перемикач теми та одиниць у шапці екрану.
- **Стани завантаження та помилок:** плавні скелетони (`WeatherSkeleton`) замість різких спінерів та екран помилки з кнопкою повторного запиту (`Retry`).

## 🏛 Архітектура та організація коду

```
├── app/                      # Екрани та роутинг (Expo Router)
│   ├── _layout.tsx           # Кореневий стек навігації, QueryClientProvider, тема
│   ├── index.tsx             # Головний екран (пошук, геолокація, список улюблених)
│   └── city/[id].tsx         # Екран міста (поточна погода, прогноз на 7 днів)
├── src/
│   ├── api/                  # API-шар (Open-Meteo REST клієнт, 0 fetch у компонентах)
│   │   ├── client.ts         # Базовий типізований HTTP-клієнт та обробка ApiError
│   │   ├── geocoding.ts      # Geocoding API запити пошуку міст
│   │   ├── weather.ts        # Forecast API запити та нормалізація структури даних
│   │   └── queryClient.ts    # Конфігурація TanStack Query
│   ├── components/
│   │   ├── ui/               # Базові компоненти (Input, Skeleton, ErrorState, OfflineBanner, HeaderControls, BackButton)
│   │   └── weather/          # Доменні компоненти погоди (CitySearch, FavoriteCityCard, CurrentWeatherView, DailyForecastList)
│   ├── constants/            # Теми оформлення (світла/темна палітра)
│   ├── hooks/                # Кастомні хуки (useCitySearch, useWeather, useDebounce, useLocation, useThemeColors)
│   ├── store/                # Zustand сховища (useFavorites, useSettings, safeAsyncStorage)
│   ├── types/                # TypeScript моделі (API DTO, погода, обране)
│   └── utils/                # Чисті функції (форматування чисел/дат, мапінг WMO кодів)
```

## 💡 Що можна покращити з додатковим часом

1. **Графік погоди по годинах (Hourly Forecast):** додати горизонтальний скрол погоди на кожні 3-6 годин для поточної доби.
2. **Анімації переходів (React Native Reanimated):** додати Shared Element Transitions при переході з картки обраного міста на головному екрані до екрану прогнозу.
3. **Фонове автооновлення (Background Fetch):** оновлювати погоду для улюблених міст у фоні, щоб при відкритті користувач завжди мав найсвіжіші дані навіть до першого запиту.
4. **Push-сповіщення про погодні аномалії:** попередження про шторм або різкі перепади температури за даними WMO кодів.
5. **E2E тестування:** додати наскрізні тести на базі Maestro або Detox для тестування ключових призначених для користувача сценаріїв на реальних девайсах.
